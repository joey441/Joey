# 💫 About Me:
"Financial Engineering student and code enthusiast. I specialize in turning raw financial data into actionable insights. My technical stack is focused on the full pipeline: I use SQL to query and organize data, Python (Pandas, NumPy) to analyze it, and R for deep statistical validation. On the frontend, I enjoy using modern frameworks to build dashboards that make complex financial concepts accessible to users. I’m always looking for interesting projects that sit at the intersection of quantitative finance, data science, and user experience."
